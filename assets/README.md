# Kilkari website assets

Put public website media in this folder. Files here are deployed alongside
`index.html` and can be referenced with paths such as:

```html
<img src="assets/logo.png" alt="Kilkari Preschool">
```

Suggested file names:

- `logo.png` or `logo.svg` — Kilkari logo
- `hero-image.jpg` — optional hero photograph
- `program-playgroup.jpg`, `program-nursery.jpg` — program imagery
- `gallery-01.jpg`, `gallery-02.jpg` — consent-cleared gallery images
- `favicon.png` — browser icon

Only add media that Kilkari owns or is licensed to use, especially photographs
of children. Keep image files optimized for the web where possible.
